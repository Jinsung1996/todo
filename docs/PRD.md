# PRD: 할 일 관리 앱

## 1. Why - 목적

* 할일/주간계획/연간목표를 하나의 구조로 연결하여 실행 추적
* 드래그 앤 드롭 기반 상태 관리로 빠른 작업 흐름 제공
* 주간 진행률 자동 집계로 목표 대비 실적 가시화

## 2. Who - 타깃 사용자

* 개인 목표 관리자 (셀프 매니지먼트 사용자)
* 연간 목표를 세분화해 실행하는 1인 생산성 사용자
* 주 단위로 할일을 계획/리뷰하는 사용자

## 3. User Flow

1. 1년 목표 생성
2. 1년 목표 하위에 주간계획 생성
3. 주간계획 하위에 할일 생성/조회/수정/삭제 (CRUD)
4. 날짜·주간계획·상태 조건으로 할일 조회 및 보드에서 상태 확인 (todo/doing/done)
5. 드래그 앤 드롭으로 할일 상태 변경
6. 할일 생성/수정/삭제·상태·주간계획 연결 변경 시 주간 진행률 자동 갱신
7. 주간 진행률 또는 연간 목표에 연결된 주간계획 변경 시 연간 목표 진행률 자동 갱신 (P1)

## 4. 기능 요구 사항

### P0 - 핵심 기능

* 할일 생성
* 할일 조회 (목록 및 개별 할일 상세)
* 조회 조건: 할일 날짜·연결된 주간계획·상태 (todo/doing/done); 조건 조합 시 모두 충족하는 할일만 표시
* 조회 조건 미지정 시 전체 할일 조회; 일일 할일 뷰는 선택 날짜 기준, 기본값은 오늘
* 할일 수정
* 할일 삭제
* 할일 상태 필드 (todo/doing/done)
* 보드 뷰 (상태별 컬럼)
* 드래그 앤 드롭으로 상태 변경
* 일일 할일 뷰
* 주간계획 생성/수정/삭제
* 1년 목표 생성/수정/삭제
* 할일 ↔ 주간계획 연결
* 주간계획 ↔ 1년 목표 연결
* 주간 진행률 자동 계산: 해당 주간계획에 연결된 done 할일 수 / 연결된 전체 할일 수 × 100
* 주간 집계 기준: 삭제된 할일 제외, todo/doing은 미완료로 처리, 조회 조건과 무관하게 연결된 전체 할일 집계
* 주간 진행률 예외: 연결된 할일이 0개이면 0%; 연결 해제된 할일은 기존 주간계획 집계에서 제외
* 주간 재계산 조건: 할일 생성/수정/삭제·상태 변경·주간계획 연결/해제 저장 성공 시 즉시 재계산 (조회만으로는 재계산하지 않음)
* 주간계획 연결 이동 시 이전·새 주간계획 모두 재계산; done에서 todo/doing으로 변경 시 완료 수 감소 반영
* 주간 진행률 UI 표시 (%, 진행바)

### P1 - 추가 기능

* 할일 우선순위 설정
* 할일 마감일 설정
* 연간 목표 진행률 자동 집계: 해당 목표에 연결된 주간계획 진행률(%)의 합 / 연결된 주간계획 수 (동일 가중치 평균)
* 연간 집계 예외: 연결된 주간계획이 0개이면 0%; 할일이 없는 주간계획도 진행률 0%로 평균에 포함
* 연간 재계산 조건: 하위 주간 진행률 갱신 또는 주간계획 생성/삭제·목표 연결/해제 저장 성공 시 즉시 재계산
* 주간계획의 목표 연결 이동 시 이전·새 연간 목표 모두 재계산; 삭제·연결 해제된 주간계획은 기존 목표 집계에서 제외
* 주간 리뷰 요약 뷰
* 할일 추가 필터/정렬 (P0의 날짜·주간계획·상태 조회 외)
* 완료 할일 아카이브 (삭제와 구분하며 주간·연간 진행률 집계에 포함)
